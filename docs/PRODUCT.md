# Référence produit — TRANSORA

## Positionnement
« L'infrastructure numérique qui fait fonctionner l'entreprise de transport de bout en bout. »

La promesse n'est pas seulement de vendre des billets : centraliser l'exploitation et rendre l'activité mesurable.

## Expérience cible
La complexité doit être absorbée par le moteur. Les écrans doivent privilégier :
- actions évidentes
- libellés courts
- repères visuels
- parcours rapides
- information adaptée au rôle
- usage mobile quand pertinent.

## Parcours commercial
### Voyageur
Origine → destination → date → options directes/correspondances → départ → siège → passager → paiement → billet.

### Guichetier
Destination → date → départ → siège → passager → paiement → émission.

### Contrôleur
Choisir départ → scanner → résultat immédiat → statut → synchronisation.

### Direction
Vue synthétique → anomalies → détails par gare/ligne/départ → décision.

## Valeur pour l'entreprise
- centralisation
- réduction des erreurs de réservation
- meilleure occupation
- contrôle des recettes
- visibilité flotte/personnel
- traçabilité
- distribution multi-canal
- accès à de nouvelles destinations via correspondances
- données opérationnelles.

## Indicateurs produit
Billets traités, voyageurs, taux d'occupation, revenu transport, frais TRANSORA, taux de validation, no-show, annulations, retards, pannes, écarts de caisse, taux de correspondances réussies.

## TrouveTout
TrouveTout est un client/canal de TRANSORA. Une entreprise doit pouvoir vendre directement même si TrouveTout est indisponible.
